Privacy policy

Last updated 20 November 2026

Who uses it

This tool is used only by its owner, for the owner's own Google account. No one else signs in to it.

What it reads

With the owner's consent, read-only access to the owner's Google Classroom:

  • the list of courses (classroom.courses.readonly)
  • coursework and the owner's own submission status (classroom.coursework.me.readonly)
  • course announcements (classroom.announcements.readonly)

It cannot create, change, submit or delete anything in Google Classroom.

What it does with it

It finds upcoming tests, deadlines and class changes and sends a short summary to the owner's own Telegram chat. Nothing is sold, shared with third parties, used for advertising or used to train AI models.

What it keeps

Only what it needs to notice changes: the IDs of announcements already seen and the owner's class timetable, kept in the owner's private GitHub Actions cache. Course content is not stored. The sign-in token is kept as an encrypted secret in the owner's private repository.

Stopping access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
