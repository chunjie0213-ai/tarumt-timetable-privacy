Privacy policy

Last updated 20 November 2026 (Drive access added)

Who uses it

This tool is used only by its owner, for the owner's own Google account. No one else signs in to it.

What it reads

With the owner's consent, read-only access to the owner's Google Classroom:

  • the list of courses (classroom.courses.readonly)
  • coursework and the owner's own submission status (classroom.coursework.me.readonly)
  • course announcements (classroom.announcements.readonly)
  • files posted in Classwork (classroom.courseworkmaterials.readonly)
  • read-only Google Drive access (drive.readonly), used to open schedule files that teachers attach in Classwork

Although Google's Drive permission covers every file the owner can see, the tool only opens files attached to the current semester's Classroom courses whose name marks them as a schedule (for example "FYP Deadline"). It does not list, search or open any other Drive file.

It cannot create, change, submit or delete anything in Google Classroom or Google Drive.

What it does with it

It finds upcoming tests, deadlines and class changes and sends a short summary to the owner's own Telegram chat. Nothing is sold, shared with third parties, used for advertising or used to train AI models.

What it keeps

Only what it needs to notice changes: the IDs of announcements already seen, the owner's class timetable, and the dates and task names read from schedule files, kept in the owner's private GitHub Actions cache. Other course content and file contents are not stored. The sign-in token is kept as an encrypted secret in the owner's private repository.

Stopping access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
